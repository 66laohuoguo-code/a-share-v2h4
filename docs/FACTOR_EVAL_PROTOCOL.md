# 因子评估协议

> 本文只讲**方法**，不含任何具体因子的公式、参数或业绩数字。
> 所有示例数字来自 `python -m factor_eval.cli demo` 的**合成**面板。
> 配套实现见 `factor_eval/`，测试见 `tests/test_factor_eval.py`。

---

## 0. 为什么需要一套"否决流程"

在一个横截面因子的研究项目里，真正的稀缺资源不是想法，而是**可信的否决**。
想法几乎总是能找到一个控制集让它看起来显著。一套好流程的价值在于：
它能在你花两周做组合回测之前，把其中绝大多数想法杀掉，并且**杀得有据可查**。

下面五道检查按"应当跑的先后顺序"排列。前两道必须在看业绩**之前**跑。

---

## 1. 门一：可分组性（先问"能不能测"，再问"测出来多少"）

**问题**：分位数统计（分组均值、单调性、多空价差）默认信号在截面上足够分散。
若某信号在 70% 以上的截面上取同一个值，五个分位组根本建不出来。
此时把结果报成"没有组间价差"是**归因错误** —— 正确结论是
`inapplicable: signal too tied for quantiles`。

**检查**：逐期记录

| 指标 | 含义 |
|---|---|
| `unique_score_count` | 当期不同取值个数 |
| `largest_tie_fraction` | 当期最大并列组占截面的比例 |
| `groupable_week_fraction` | 同时满足前两项门槛的周数占比 |

**预注册门槛**（示例值，可按品种调整）：取值 ≥ 50、最大并列 ≤ 0.20、可分位周占比 ≥ 0.80。

**关键点**：门槛要**故意设成让已知的离散计数型信号不通过**，并把它变成一道
**前置门**而不是事后解释。否则每换一个信号就要重新争一遍"这算不算不显著"。

**离散化带来的另一种伤害**：即便并列不严重，把连续信号粗分箱也会损失大量信息。
一个取值只能落在 `k/20` 格点上的信号，其分位验收基本不可用。

---

## 2. 门二：控制可用性（列存在 ≠ 有效控制）

**问题**：回归里放了一个在某段数据上**恒为常数**的控制列，它对斜率没有任何约束作用，
但报告里会写"已控制该风格"。这会**静默地**让结论偏乐观。

**检查**：逐控制列 × 逐时代统计 `n_unique` 与 `sd`，把 `n_unique == 1` 的标出来；
另外做控制列的**两两秩相关**，把 |ρ| ≥ 0.98 的共线对标出来。

**为什么必须在看业绩前跑**：如果一段数据的风格控制实际上是失效的，
那么这段里的"增量显著"和"增量归零"都不可解释 —— 你无法区分是信号的问题
还是控制集的问题。

**典型来源**：不同年代、不同数据供应商、不同股票池版本拼出来的面板。
只在一段数据里存在的风格暴露，在另一段可能整列缺失或退化为常数。

---

## 3. 协议一：消融阶梯 + 子区间衰减

**问题**：只报告"控制住 N 个风格后仍然显著"没有意义 —— 要看 **N 是什么**。
换一组控制就能改变结论的报告，等于没有结论。

**做法**：预注册一个**有序**的层级，从最弱到最全逐层加：

```
L0  基础风格（最常用、最容易被辩称"必须控制"的那几个）
L1  + 规模 / 流动性等一阶代理
L2  + 与它同族的既有信号（"基线因子"）
L3  + 完整控制集（含与自己高度相关的那些）
```

只报 L0 会夸大；**L3 才是"相对现有体系有没有增量"的答案**。
本项目的一条经验教训是：**逐层加入后，受控斜率往往被压缩数倍**。

**子区间拆开看**（辛普森式陷阱）：把同一份消融按时间子区间分别跑。
若某个层级的 t 逐段单调衰减（例：3.4 → 1.7 → 1.1），
那"全期显著"只是一个**平均值假象**，是被早期段抬起来的。
**必须如实报告衰减，而不是只报全期。**

---

## 4. 协议二：反转向复检

**问题**：研究中经常出现"符号与预期相反"。翻符号之后还剩多少信息？
**翻符号不等于数据挖掘** —— 如果翻过来之后仍与反转正交，那是一种"对市场信息的再利用"；
如果翻符号只是把因子变成短期反转的马甲，那它没有增加任何东西。

**协议（每一步都不可省）**：

1. **两个对象都要测**：
   * `raw` —— 因子原值；
   * `res` —— 对**反转基准**（通常是过去 N 日收益）做逐期截面正交后的残差。
   有些因子的原始与残差**符号相反**（抑制效应）。只测一套会把真正有信息的那一侧当成"错的"丢掉。
2. **符号只在训练段选定**，冻结后搬到测试段。测试段是纯样本外。
3. **门槛按试验数做 Bonferroni 校正**，并且必须是**双边**的
   （因为符号是两侧选的，翻符号本质上把试验数翻倍）：
   `n_trials ≈ 候选数 × 2 个符号 × 2 个对象`。
   参考值：56 → |t| ≥ 3.32；112 → 3.51；196 → 3.66。
4. **幸存者必须再通过"加回风格"检验**：把先前剔除的全部风格（以及现有体系的分数）
   放回控制集，偏斜率 t 仍需 ≥ 3。

### 教训 A：低相关 ≠ 独立

演示（合成数据）：一个因子与反转的**秩相关只有 −0.566**，原始版本两段 t 都超过 23。
把它对反转做逐期截面正交后，**符号翻转、样本外 t 只剩 +0.54**。

原因：**单调或非线性变换可以任意压低线性相关，却完全保留单调信息**。
所以"这个因子和反转的相关只有 0.2"这句话**不能**作为独立性的证据 ——
必须做**多元投影**（截面回归取残差），再看残差还剩多少 IC。

**推论**：报告独立性时，不要只给相关系数矩阵；要给"正交化之后还剩多少"。

### 教训 B：正交掉反转还不够，要把剔除的风格加回来

演示：`value_style` 原始版本 t 超过 25，正交掉反转后依然显著；
把 `value` 加回控制集，偏斜率 t 立刻变成 **−0.46**。
它不是新因子，它就是那个被剔掉的风格。

**一般化的规则**：任何"某信号在控制 X 之后仍显著"的结论，
都必须回答一个反问 —— **X 是谁选的？如果 X 是你自己挑的，那把被挑掉的那些加回来会怎样？**
常见做法是维护一份"可比控制集"，并**明确记录哪些风格被排除了、为什么**；
一旦有因子在这个排除集上活下来，第一件事就是把它加回去重测。

## 5. 协议三：分位画像 —— IC 与组合层是否脱钩

**问题**：一个信号的 IC 可以很显著、跨期很稳定，但按它做的**只做多组合**仍然亏钱。
提前诊断这一点，可以省掉整轮组合回测。

**做法**：算每一分位组的池化均收益，并与**全池等权基准**对比。三个量：

| 量 | 读法 |
|---|---|
| `top − pool` | 头部组本身贡献了多少 |
| `pool − bottom` | **规避**底部组贡献了多少 |
| 单调性 | 分组次序是否可解释 |

**判据**：若 `top − pool` 远小于 `pool − bottom`（例如不到四分之一），
说明 **alpha 在规避端**：信号的信息主要是"别持有最差的那一档"，
而不是"持有最好的一档"。此时只做多的头部组合赚不到信号的钱，
再叠加换手成本就很容易转负。

**这类信号的正确用法是负面筛选 / 风险剔除**，而不是当多头因子 ——
但那需要另立预注册，不能拿原来的多头结论去改判。

## 6. 评估通过 ≠ 可以交易

排序关联、增量、分位画像是**统计**层。要谈交易价值，还要单独回答：

1. **成交可行性**：信号最想持有的标的是不是恰恰买不进/卖不出？
   （涨跌停、停牌、流动性枯竭）这一项在真实项目里往往是**最大的单项损失**。
2. **换手与成本**：单向换手 × 双边成本，年化拖累是多少？与 IC 的量级比是否划算。
3. **容量**：`participation = 下单金额 / ADV`，按 ADV 的低分位保守估计。
4. **记账口径**：**不要用原始价给持仓计价** —— 拆股/送转会被当成真实亏损，
   能造出符号都反了的虚假回撤。应按市值记账 + 用总收益序列演化。
5. **路径相依性**：20 日前瞻收益的**横截面均值**关联，与一个**复利累积**的组合收益
   不是同一个量。趋势型信号可以"IC 不显著但组合赚钱"，也可以反过来
   （"IC 显著但组合亏钱"）。两者必须分开报告，不能互相替代。

## 7. 一页清单

```
看业绩之前
  [ ] 门一 可分组性：取值数 / 最大并列 / 可分位周占比
  [ ] 门二 控制可用性：常数控制列、共线控制对
  [ ] 预注册：控制集层级 L0..L3、子区间、门槛、试验数

看业绩
  [ ] 消融阶梯：逐层加控制，报 L3 而不是 L0
  [ ] 子区间衰减：逐段拆开，报告是否单调衰减
  [ ] 反转向复检：raw 与 res 两套、符号冻结、Bonferroni 双边门槛
  [ ] 加回剔除的风格：偏斜率 t 是否仍 ≥ 3
  [ ] 分位画像：alpha 在头部还是在规避端

谈交易之前另外回答
  [ ] 成交可行性 / 换手成本 / 容量 / 记账口径 / 路径相依性
```

**最后一句**：这套流程的目标是让"杀掉一个想法"变得**便宜且可复现**。
一个项目真正的资产，是它记录下来的、有据可查的否决意见。
